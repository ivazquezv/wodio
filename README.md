WODIO

WodIO es una plataforma de gestión diseñada para boxes de CrossTraining y gimnasios funcionales. Su objetivo es optimizar la organización diaria, mejorar la experiencia de los atletas y proporcionar herramientas avanzadas de análisis y control para propietarios y entrenadores.

DESCRIPCIÓN GENERAL

Este repositorio contiene la página oficial de WodIO, desarrollada como una landing estática orientada a la presentación del producto y a la captación de nuevos clientes. La web muestra las funcionalidades principales de la plataforma, los planes disponibles y los canales de contacto.

CARACTERÍSTICAS

Gestión de clases y horarios

Control de atletas y asistencia

Panel de métricas y estadísticas

Programación semanal de entrenamientos

Gestión de pagos y suscripciones

Diseño responsive adaptado a dispositivos móviles y escritorio

TECNOLOGÍAS UTILIZADAS

HTML5

CSS3

JavaScript

Phosphor Icons

Netlify (despliegue)

GitHub (control de versiones)

INSTALACIÓN

Clonar el repositorio:

git clone https://github.com/ivazquezv/wodio.git

Acceder al directorio del proyecto:

cd wodio

Abrir el archivo principal:

public/index.html

El proyecto funciona como una landing estática y no requiere instalación adicional.

DESPLIEGUE

El sitio está configurado para desplegarse en Netlify utilizando la carpeta "public" como directorio de publicación.
Cada actualización en la rama "main" genera un nuevo despliegue automático.
